# LIVE DATA #2 — SIGUNGU target population

주 분석 단위는 `PRIMARY_ANALYSIS_LEVEL=SIGUNGU`입니다. 인구 근거로 탐색된 지역을 보여주며, 인구만으로 시설 부족·최종 후보·최종 부지를 정하지 않습니다.

## 정규 코드와 실제 지도

행정표준코드관리시스템의 [법정동 코드 전체 다운로드](https://www.code.go.kr/stdcode/regCodeL.do) 원본 ZIP과 SHA256을 `data/geography/sigungu/`에 보존했습니다. `MOIS_LEGAL_SIGUNGU` 이름공간의 공식 법정동 코드 앞 5자리이며 KOSIS 제공자 코드는 별도로 보존합니다. 기준은 다운로드 당시의 존재/폐지 상태입니다. 원본에는 변경 시행일이 없어 상태를 과거에 소급하지 않습니다.

현재 존재 시군구 코드 269개 중 일반구를 가진 상위 시 13개를 중복 합산하지 않아 기본 분석 대상은 **256개**입니다. `경기도 → 용인시 → 기흥구`처럼 parentSidoCode/Name과 parentCityCode를 보존합니다. 세종의 법정동 시군구 코드는 있지만 KOSIS 시도 집계 행을 자동 승격하지 않습니다. 동일 이름만으로 신·구 지역을 이어 붙이지 않습니다. `중구` 등 단독 명칭은 모호하면 UNRESOLVED/AMBIGUOUS입니다. 공식 전체 이름이나 명시적 부모의 전체 경로가 일치해야 합니다. 공백 없는 시+구 표기는 동일 전체 경로의 공백 차이만 정규화합니다.

기존 작은 지명 사전의 검색 근거 경로는 호환성을 위해 유지하며 새 구조화 분석은 동일 RegionReference 계약에 공식 regionCode와 `sigungu:{code}` 내부 id를 넣습니다. 시설 공급도 이 등록부만 사용합니다. SIDO/NATIONAL은 맥락이며 시군구로 배분하지 않습니다. 읍면동 통계는 분석 범위 밖입니다.

지도는 SGIS 원자료를 가공한 [vuski/admdongkor](https://github.com/vuski/admdongkor) 커밋 `dd1881663fcabc69b81393604e91ebf3a4202e9a`, 2026-07-01 경계입니다. 원본 sgg 코드별 실제 폴리곤을 병합하고 화면 표시를 위해 0.0007도 이내 단순화했습니다. `scripts/build-sigungu-assets.py`로 재현합니다(일회성 Python shapely, 앱 의존성 없음). 256개 경계와 정규 코드를 검증하며 모르는 값은 NO DATA입니다. 지도 클릭은 조회 대상을 선택할 뿐 후보를 생성하지 않습니다. 기존 KoreaMap과 RegionDetail에 시군구 경로를 추가했습니다. 기존 2021 시도 지도는 과거 비구조화 근거의 맥락 화면에만 남습니다.

출처/라이선스는 데이터 폴더와 지도에 표시합니다: SGIS 공공누리 제1유형; vuski/admdongkor 가공 CC BY 4.0. 경계의 출처 날짜와 인구의 기준일은 별개입니다. 지도는 법적 경계 판정 도구가 아닙니다.

## 대상 인구 정의

`TargetPopulationProfile`은 시설·복수 집단·명시적 나이 범위·가구 관련 확인사항·근거·definitionId를 가집니다. 동일 엔진을 재사용합니다.

- 어린이집: 프로젝트 분석 범위 만 0–5세. 법적 입소 가능 연령 전체라는 주장은 아닙니다. 설정 UI에서 조정 가능합니다.
- 노인복지관: [KOSIS 고령인구 기준](https://kosis.kr/visual/populationKorea/PopulationDashBoardMain.do)의 65세 이상. 실제 복지관 이용 자격과는 별개입니다.
- 청소년 문화시설: [청소년 기본법 제3조](https://www.law.go.kr/법령/청소년기본법/제3조)의 9–24세를 분석 범위로 설정합니다.
- 도서관 및 지역 주민 대상 시설: 전체 주민등록인구. 연령 기반 보조 집단은 설정 가능.
- 연령만으로 정의하기 어려운 시설: UNCONFIGURED. 임의 나이 범위를 만들지 않습니다.

KOSIS는 [매월 말일 기준 만 나이](https://kosis.kr/civilComplaint/qnaDetail.do?boardIdx=22124)입니다. 데이터의 연령 셀을 정확히 합산하고 중복 구간을 더하지 않습니다. 65세 이상은 100세 이상 개방 구간까지 포함 여부를 확인합니다. 셀 하나라도 누락/중복/비수치이면 TARGET_POPULATION은 MISSING입니다.

## 인구 데이터

[공식 대량통계 목록](https://kosis.kr/statisticsList/mass/mass_list.jsp?org_id=101&process=statHtml&tbl_id=DT_1B04006)에서 `101 / DT_1B04006`, 행정구역(시군구)별/1세별 주민등록인구, 월별 자료와 시군구/연령 구성을 확인했습니다. 현재 목록은 2026-08까지 월 자료를 제공합니다. HTML 표의 수치를 수집하지 않습니다.

실제 앱은 기존 KosisClient HTTPS OpenAPI만 사용합니다. TBL/ORG/PRD/ITM/UNIT 원본을 조회하고 총 인구수 항목, 첫째 지역 분류와 둘째 연령 분류, 전체 연령의 계 및 요청 나이를 메타데이터에서 확인합니다. 미확인 코드·추정 비율은 사용하지 않습니다. 응답의 표·기관·항목·시점·단위·분류를 다시 검증합니다. 값·원본 행·표·기관·시점·분류·합산식·inputMetricIds를 보존합니다. 통계표의 API 세부 계약은 키가 주어지면 실제 응답으로 최종 검증해야 합니다.

최근 수록 연도가 있으면 연 단위, 아니면 월 단위를 사용합니다. 기본 비교 창 5년(1/3/5/10년 선택). 실제 PRD 메타데이터의 최신 시점과 해당 창 안의 가장 오래된 동일 월(또는 연) 시점만 선택합니다. 5년이 없고 3년이 있으면 그 시점을 표시합니다. 현재/과거 각 한 번의 표 단위 요청으로 모든 지역과 필요한 나이만 조회하며, 지역별 수백 요청은 하지 않습니다. 캐시/제한은 LIVE DATA #1을 재사용합니다.

## 파생 지표와 비교

동일 시군구·기준일·명 단위·주민등록 모집단·성별 합계·동일 통계표에서 target / total을 계산합니다. 분모 0, 대상 인구가 전체보다 큼, 중복 수치 등은 계산하지 않습니다. 비율은 원 단위 0~1이며 % 변화율과 구별합니다.

증감은 latest - previous, 변화율은 (latest - previous) / previous * 100입니다. 시작/끝 시점, 입력 지표 ID, 원본 증거 ID와 표를 보존합니다. **KOSIS의 이 계약만으로 과거 경계 동일성을 입증하지 못하므로 현재 어댑터는 boundaryVersion=null이며 역사 증감 계산은 보류합니다.** 검증된 같은 경계 버전의 자료가 추가되면 같은 엔진이 계산합니다. 공급 시계열과의 관계도 이 검증을 통과해야 합니다. 이름/코드가 같다는 이유만으로 경계가 불변했다고 가정하지 않습니다.

비교 집단은 동일 지표·대상 정의·모집단·시군구 분석 단위·기준일·기간·단위·표를 사용합니다. 백분위는 `100 * (작은 값 개수 + 같은 값 개수 / 2) / 유효 지역 수`입니다. 동률은 같은 위치이며 1개 지역은 상대위치를 만들지 않습니다. 결측과 DEMO는 제외하고 비교 지역 수를 표시합니다. 백분위는 필요 점수가 아닙니다. 높은/급격한 현상을 임의 절대 기준으로 표시하지 않습니다. 호환 증감만 성장·감소·유지 Phenomenon을 생성하며 공급과의 관계를 인구만으로 만들지 않습니다.

## UI와 누락 보고

시설 해석 후 기존 LIVE SEARCH 모드에서 시군구 대상인구 패널을 사용합니다. Brave 키와 독립적입니다. 목록은 지역 이름순이며 대상인구/비율/증감/변화율 정렬을 선택할 수 있습니다. 모든 256개 분석 대상이 페이지 목록과 지도에 남습니다. 전체/정상/일부 누락/NO DATA/비교 보류와 매핑 실패 원본 행 수를 구분합니다. 전국·시도 원자료는 실패한 시군구로 세지 않고 맥락으로 보존합니다.

모드 또는 시설 변경 시 컴포넌트와 요청을 초기화합니다. LIVE 분석에서 DEMO는 현상·비율·비교·지도·순위에 기여하지 않습니다. 경계·키만 연결되었다고 인구 LIVE를 표시하지 않습니다.

## 실제 검증 한계

공식 코드 ZIP과 실제 경계 GeoJSON은 수신·검증했습니다. KOSIS_API_KEY가 없는 환경에서는 실제 인구 행이 없으므로 정상 데이터 0, 256개 NO DATA입니다. 이 상태의 매핑 실패 0은 매핑 정확도 100%를 뜻하지 않습니다. 실측 SIGUNGU 인구 예시를 만들어내지 않습니다. 테스트 값은 TEST ONLY로 분리합니다.


## 2026-09-22 실제 KOSIS 연결 검증 완료

이전 API 키 미설정 기록은 과거 상태입니다. 현재 실제 응답 → 정규 시군구 → UI LIVE 표시를 검증했습니다. 최신 2026-08 자료는 256개 시군구에 연결됐으며, 전체 103개 테스트와 빌드가 통과했습니다. 상세 수신 범위·실제 값·한계는 [검증 보고서](KOSIS_LIVE_CHECKPOINT.md)를 참조하세요. 과거 경계 동일성은 미검증이므로 증감 계산은 보류합니다.
