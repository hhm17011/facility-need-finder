# Geographic Evidence Mapping — #5

## 목적과 범위

평가된 근거에 명시된 지역을 연결하고 **추가 조사 후보**를 보여줍니다. 최적 부지·필지·건축 위치를 선정하지 않습니다. 지명 출현 횟수가 후보 점수가 되지 않습니다.

```text
EvaluatedEvidenceItem[]
  → regionNormalizer / 명칭 사전
  → RegionMapping[]
  → RegionEvidenceProfile[]
  → 자료 충분성 검사 + Candidate Score + Confidence
  → 최대 50개 후보 / 지도 / 지역별 근거 상세
```

## 정규화

`regionCatalog.ts`는 17개 광역 명칭과 광주광역시 북구, 경기도 광주시, 용인시·기흥구, 평택시, 서울·부산 중구 등의 소규모 명칭 예시를 포함합니다. 전국 시군구 전수 데이터가 아닙니다.

명칭 검토에 사용한 공식 출처:

- [광주시청](https://www.gjcity.go.kr/): 경기도 광주시 표기
- [용인시 공공체육시설](https://publicsports.yongin.go.kr/publicsports/sports/selectFcltyRceptResveViewU.do?checkSearchMonthNow=false&key=&pageIndex=24&pageUnit=8&resveId=14227): 경기도 용인시 기흥구 표기
- [광주 북구의회](https://council.bukgu.gwangju.kr/aac/): 광주광역시 북구 표기

이 사이트들은 명칭 참고 출처이며, 앱이 시설 필요성의 근거로 수집한 자료가 아닙니다. 통계·정책 내용을 복사하거나 후보 근거로 삽입하지 않았습니다.

`RegionReference`는 국가, level1/2/3, 표시명, 원문 표기, 정규화 상태, 확신도와 가능한 지역 목록을 가집니다. `id`는 내부 사전 키이며 공식 코드가 아닙니다. 검증된 코드 테이블을 연결하지 않았으므로 `regionCode`는 null입니다.

- 전체 정규 명칭과 일치: 정규화 확신도 0.98
- 안전한 등록 별칭(용인, 용인시, 기흥구 등): 0.95
- 광주: 광주광역시 / 경기도 광주시 간 모호함
- 중구·북구·남구·동구·서구 단독 표기: 모호함. 사전에 가능한 지역이 한 개만 있어도 유일하다고 가정하지 않음
- 미등록 표기: unknown
- 명시적 대한민국/전국/NATIONAL: national

이 수치는 규칙 일치의 시제품 표지이며 확률적으로 교정된 값이 아닙니다. 과거 명칭 별칭을 현재 표시명으로 연결할 수 있지만 과거 경계·행정구역 변경을 복원하지는 않습니다.

## 연결 근거

제목, 검색 스니펫, 기존 추출 주장·수치의 원문 발췌, 제공된 지리 범위만 읽습니다. 발행기관명·출처 사이트 주소·검색어·AI 생성 요약으로 지역을 추론하지 않습니다. 주소/소재지/연락처/발행기관 등으로 표시된 연락처 구간은 제외합니다.

긴 연속 표기를 우선합니다. `경기도 용인시 기흥구`를 발견하면 같은 표현의 경기도·용인시를 별도 지역으로 중복 귀속하지 않습니다. 다른 필드에 상위 명칭이 반복되어도 해당 자료에 명시된 가장 구체적인 하위 지역으로 연결합니다. 상위 또는 하위 지역으로 자동 전파하지 않습니다.

`mentionedRegions`만 있고 실제 제목·스니펫·발췌에서 표기를 찾지 못하면 검증되지 않은 메타데이터로 남깁니다. 모호한 지명을 문서 어디엔가 있는 다른 도시명과 임의로 결합하지 않습니다. `서울 중구`처럼 연속된 등록 표기가 있어야 해소합니다.

각 `RegionMapping`은 근거 ID, 정규 지역, 원문 표기, 필드, 실제 인용 텍스트, 연결 이유와 확신도를 보존합니다. 문자열 일치는 자료의 논지가 그 지역의 시설 수요를 직접 입증한다는 뜻이 아닙니다.

## 전국과 지역

- 원문의 제공된 지리 범위가 명시적으로 NATIONAL/전국이면 전국 배경으로만 분류합니다. 근거에 다른 지역 메타데이터가 있더라도 도시별 점수를 만들지 않습니다.
- 텍스트에 전국 표기가 있고 명시적 개별 지역이 없으면 전국 배경입니다.
- 개별 지역과 전국 비교 표현이 함께 있다면 전국 배경을 보존하면서 **실제로 명시된 개별 지역만** 연결할 수 있습니다. 모든 도시에 자동 배분하지 않습니다.
- 모호한 표기는 후보 계산에 사용하지 않고 위치 확인 목록에 표시합니다. 후보 예시는 전수 목록이 아닙니다.
- 지역도 전국 범위도 확인할 수 없으면 미연결 자료로 유지합니다.

역할은 원래 평가를 보존하여 다음처럼 표시합니다.

- `REGION_DIRECT`: 기존 DIRECT 판정이 있고 한 개의 명시 지역에 연결된 자료
- `REGION_CONTEXT`: 기존 CONTEXT 판정이 있는 지역 자료
- `NATIONAL_CONTEXT`: 전국 배경
- `UNKNOWN`: 그 외. 복수 지역 문서는 각 지역의 직접 수요 증거로 자동 승격하지 않음

현재 의미 분석기가 없으므로 실제 기본 흐름의 지역 직접성·수요 방향은 대부분 UNKNOWN입니다. 미판정을 배경이나 수요 지지로 바꾸지 않습니다.

## 화면

#1 KoreaMap과 RankingPanel을 후보 데이터 계약에 맞게 재사용하고 RegionDetail을 실제 연결 근거 표시로 갱신했습니다. 예전 Need Score 목업을 후보 점수로 변환하지 않습니다.

- 지도·목록 선택은 같은 지역 ID로 동기화됩니다. 마커는 Enter/Space로도 선택할 수 있습니다.
- 표시는 개략도입니다. 사전의 권역별 표시 위치는 실제 좌표·행정경계가 아닙니다. 마커 크기에 후보 점수를 반영합니다.
- 검색은 현재 후보 지역명에만 적용합니다. 필터 후에도 기존 후보 순번·점수는 유지됩니다.
- 지역 상세의 유형 필터는 자료 표시만 바꾸고 점수·확신도는 재계산하지 않습니다.
- 자료 충분성이 낮은 지역은 `추가 확인 지역`에 보존하며 순위·지도 후보에는 포함하지 않습니다.
- 원문 링크, 상반된 근거, 배경, 미판정 근거를 각각 확인할 수 있습니다.
- WHY는 실제 제목·연결 필드·인용·기존 평가만 사용한 설명입니다. 3–5개를 목표로 하되 충분한 대표 자료가 없으면 적게 표시하고 새로운 지역 수요 주장을 생성하지 않습니다.

## 남은 한계

전국 시군구 전수 사전, 공식 행정코드, 정확한 좌표·경계, 문서 전체에서의 지리 관계 추론, 의미 분석에 의한 장소별 수요 방향 구분을 구현하지 않았습니다. 지명 일치에 따른 언급·조사 장소·비교 대상의 차이도 완전히 해석하지 못하므로 UNKNOWN과 낮은 Confidence를 보존합니다.

DEMO의 실제 지명 문자열은 가상 표시 동작을 위한 예시입니다. 동일 가상 출처를 독립 기관 여러 개로 꾸미지 않으므로 기본 DEMO는 추가 확인 지역만 있고 선정 후보가 없을 수 있습니다. LIVE 검색키가 없으면 실제 출처 수집은 하지 않습니다.

#6 문제정의 문장 생성·건축 설계·필지 선정은 시작하지 않습니다.
