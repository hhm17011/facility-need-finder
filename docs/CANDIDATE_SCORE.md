# Candidate Score and Confidence — #5

## 의미

Candidate Score는 **현재 연결 근거가 추가 지역 조사를 얼마나 뒷받침하는지** 나타내는 0–100 시제품 지표입니다. 시설 건립의 필요성 점수, 최적 부지 순위, 전문가 검증 지표가 아닙니다. 설명 없는 점수를 만들지 않습니다.

## 반복 자료 기여 제한

원문 자료는 상세에서 보존하고, 아래 과정은 점수에 사용할 대표 자료만 고릅니다.

1. 기존 URL 정규화로 추적 파라미터 등 중복을 제거합니다.
2. 동일 기관명 또는 동일 사이트 도메인은 하나의 출처 그룹으로 묶습니다. 한쪽 식별자가 겹치면 연결된 그룹도 합칩니다.
3. 공백·기호를 제거한 충분히 긴 제목이 같으면 다른 사이트에 재배포되어도 같은 그룹으로 취급합니다.
4. 출처가 식별되지 않는 자료는 하나의 미식별 그룹으로 묶고, 독립 출처 수에는 넣지 않습니다.
5. 각 그룹에서 근거 강도가 가장 높은 자료 1개만 사용합니다. 동점이면 평가 완성도를 비교합니다.
6. 같은 **주 탐색 유형**의 대표 자료는 최대 2개까지만 사용합니다. 문서 하나에 여러 탐색 분류가 붙어도 여러 유형의 독립 근거로 세지 않습니다.

도메인은 보통 마지막 두 부분, `.co.kr`/`.go.kr` 등은 마지막 세 부분으로 묶습니다. 완전한 Public Suffix List 기반 소유권 분석이 아닙니다. 기관명과 도메인은 독립성의 대리 지표이며, 서로 다른 기관처럼 보이는 신디케이션이나 이름 변형을 완전히 검출하지 못합니다. 같은 제목이지만 다른 자료를 보수적으로 묶을 수도 있습니다.

## 점수의 다섯 축

상한 처리 후 대표 자료 집합을 R로 둡니다.

| 축 | 계산 |
| --- | --- |
| 근거 강도 A | R 중 평가된 Evidence Strength의 평균 |
| 직접성 B | 역할이 판정된 R 중 REGION_DIRECT 비율 × 100. 전부 UNKNOWN이면 null |
| 출처 다양성 C | min(식별된 대표 출처 그룹 수 / 3, 1) × 100. 식별 정보가 없으면 null |
| 자료 다양성 D | min(R의 주 탐색 유형 수 / 4, 1) × 100 |
| 지역 구체성 E | 시·군·구 이하 정규 지역 100, 광역시·도 60 |

```text
Candidate Score = round(sum(가용 축 점수 × 가중치) / sum(가용 축 가중치), 1)
```

기본 가중치는 A–E 모두 1입니다. 미평가 축은 분자·분모에서 제외하고 0점으로 대체하지 않습니다. 원시 기사 수·지명 빈도는 점수 항목이 아닙니다. 최신성은 기존 Evidence Strength 안에서 반영되고, 날짜 정보의 충분성은 Confidence에도 따로 사용합니다.

예를 들어 산술 예시로 A=90, B=null, C=66.666…, D=50, E=100이면 `(90+66.666…+50+100)/4 = 76.7`입니다. 이는 실제 지역 결과를 뜻하는 예시가 아닙니다. UI에는 축별 이유·근거 원문 링크, 정밀 합계와 가중치 합을 표시합니다.

## 후보 진입 기준

다음을 모두 만족해야 후보 점수를 공개하고 순위에 포함합니다.

- 상한 적용 후 식별된 대표 출처 2그룹 이상
- 대표 자료의 평균 평가 완성도 0.6 이상
- 평균 지명 정규화 확신도 0.85 이상
- 평가 가능한 점수 축 3개 이상이며 A가 평가 가능

미달이면 `candidateScore = null`, Confidence는 INSUFFICIENT입니다. 연결된 원문과 계산 신호는 추가 확인 지역에 남깁니다. 후보는 점수 내림차순으로 최대 50개, 동점은 표시명 순입니다. 50개를 채우기 위해 지역을 생성하지 않습니다. 현재는 의미 직접성이 미판정이어도 다른 축이 충분하면 조사 후보가 될 수 있지만 Confidence는 LOW를 넘지 못합니다.

## Confidence는 별도 판단

Confidence는 점수 자체가 아니라 근거의 충분성과 판정 상태를 나타냅니다. 아래 기준은 시제품 기준이며 통계적 신뢰구간이나 검증된 확률이 아닙니다.

| 요인 | HIGH | MEDIUM |
| --- | --- | --- |
| 식별된 대표 출처 그룹 | 4 이상 | 2 이상 |
| 주 탐색 유형 | 3 이상 | 2 이상 |
| 평균 평가 완성도 | 0.8 이상 | 0.6 이상 |
| 평균 정규화 확신도 | 0.95 이상 | 0.9 이상 |
| 역할 판정 비율 | 0.8 이상 | 0.5 이상 |
| 수요 방향 판정 비율 | 0.8 이상 | 0.5 이상 |
| 최신성 평가 가능 비율 | 0.5 이상 | 0.25 이상 |

HIGH 기준을 모두 만족하면 HIGH, 그렇지 않고 MEDIUM 기준을 모두 만족하면 MEDIUM, 후보 진입 기준만 만족하면 LOW입니다. 진입 기준 미달은 INSUFFICIENT입니다. 실제 독립 출처인지·수요 주장인지 검증하지 않은 자료에 높은 확신도를 주지 않도록 역할·방향 조건을 둡니다.

## 지지·충돌·배경 보존

RegionEvidenceProfile은 원래 stance를 그대로 읽어 다음 배열을 보존합니다.

- `supportsNeed`: SUPPORTS_NEED
- `weakensNeed`: WEAKENS_NEED
- `context`: 위 두 그룹이 아니면서 CONTEXT 역할 또는 NEUTRAL 방향
- `unknown`: 나머지 미판정 자료

UNKNOWN을 건립 지지나 '반대 근거 없음'으로 바꾸지 않습니다. 수요 약화로 판정된 자료는 상세에서 먼저 보이는 별도 섹션에 둡니다. 복수 지역 문서의 방향은 여전히 장소별 의미 분석이 필요하므로 자료 전체의 원래 판정임을 이해해야 합니다.

상반된 근거를 점수에서 일괄 차감하지 않습니다. 보존 자료 중 WEAKENS_NEED이면서 Evidence Strength ≥75인 자료가 있으면 강한 충돌 신호를 남기고 확신도를 한 단계 낮춥니다(HIGH→MEDIUM, MEDIUM→LOW, LOW/INSUFFICIENT는 유지). 반복 출처 상한 때문에 점수에서 빠진 자료도 충돌 섹션과 신호에서 사라지지 않습니다. 지지 자료가 없어도 강한 반대 자료 자체가 추가 조사 후보를 가리킬 수 있습니다.

## 추적 가능성

```text
후보 지역
 → Candidate Score / Confidence
 → 축별 점수·사유·가중치·사용/제외된 근거 ID
 → RegionMapping의 실제 표기·필드·인용·확신도
 → 원래 EvaluatedEvidenceItem
 → 원문 URL
```

WHY는 대표 자료 최대 5개의 제목·표기·기존 평가를 연결하는 안전한 템플릿입니다. 충분한 자료가 없으면 적게 표시합니다. 강한 충돌 자료가 있으면 설명에서도 누락되지 않도록 포함합니다. 새로운 통계·수요·인구 변화·건립 필요성을 만들어내지 않습니다.

전국 공통 배경은 도시별 점수로 자동 전파되지 않습니다. 명시된 지역 없이 전국 자료만 있으면 후보는 0개입니다. 모호한 지명은 연결 후보 목록만 보존하고 점수에는 넣지 않습니다.

## 설정과 제한

가중치·유형 상한·충분성·Confidence·충돌·목록 크기는 `frontend/services/geography/config.ts`에서 관리합니다. AHP·전문가 비교 자료는 사용하지 않습니다. 점수는 현재 검색 결과·메타데이터·분류에 의존하며 검색 편향·출처 소유관계·미확인 날짜·제한된 지명 사전의 영향을 받습니다. 최종 입지 선정에 사용할 수 있는 모델이 아닙니다.
